# Katha (කතා) — learn spoken Sinhala

A Duolingo-style app for **everyday spoken Sinhala**, aiming at CEFR **A1**.
It's an installable web app (PWA) that runs offline, is hosted free on GitHub Pages,
and can sync your progress across devices through a free Supabase project.

## What's in it

- **Course path**: units of lessons, treasure chests, a story and a unit review per unit, plus a guidebook (tips + key phrases) for each unit.
  Units 1–4 are written (Greetings, About me, Food & drink, Numbers & money: 79 words and phrases, 57 sentences, 4 stories).
  Units 5–12 of the A1 map are shown as "coming soon".
- **Exercises**: new-word cards, picture choice, meaning choice, match pairs, translate with word tiles (or type),
  build Sinhala sentences from tiles, listen-and-tap, fill in the blank, write it (romanized typing is fine), and speak (record and compare).
  Tap any Sinhala word for its meaning.
- **Letters**: a script trainer covering vowels, consonants and vowel signs, with strength bars per letter.
- **Practice**: spaced-repetition review of your weakest words, a mistakes review, listening practice, and a word list with strength meters.
- **Motivation**: XP, daily goal, streaks (with streak freezes), hearts, gems, daily quests, achievements, a shop.
- **Sync**: email + password accounts. Progress merges safely between devices (each device's counters are kept separately, so nothing double-counts).
- **Offline**: a service worker caches the app and audio once you've opened it.

## Project layout


## 1. Put it on GitHub Pages

1. Create a **public** repository (GitHub Pages on a free account needs public), e.g. `katha`, and push this folder to `main`.
2. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. The *Build and deploy* workflow runs on every push. Your app will be at `https://<your-username>.github.io/katha/`.

## 2. Accounts & sync (Supabase) — already set up

The Supabase project **katha** (`tfnvhmuqqhukqgvylwti`, region us-west-1) is created, the `progress` table from
`supabase/schema.sql` is in place with row-level security (tested: each user sees and writes only their own row),
and `js/config.js` already holds the project URL and publishable key.

In the app: **Profile → Account & sync → Create account**. On your other devices, choose *I already have an account* (or sign in from Profile).

Two optional settings in the Supabase dashboard (**Authentication**):
- **URL Configuration → Site URL**: set it to your GitHub Pages URL so the confirmation email links back to the app.
- **Sign In / Providers → Email → Confirm email**: turn it off if you'd rather skip the confirmation email entirely.

To recreate this in a fresh project: run `supabase/schema.sql` in the SQL editor and put the new URL and publishable key in `js/config.js`.
Never put the secret / `service_role` key in the app.

## 3. Add real Sinhala voices (Azure, free tier)

Phones rarely ship a Sinhala voice, so the app plays pre-generated clips. The generator uses Azure's two
Sinhala neural voices (Thilini, female; Sameera, male). The whole course is ~400 short clips — a few thousand characters.

1. In the Azure portal, create a **Speech** resource (the free F0 tier is fine). Note its **key** and **region** (e.g. `eastus`).
2. In GitHub: **Settings → Secrets and variables → Actions → New repository secret**: add `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION`.
3. **Actions → Build and deploy → Run workflow**. It generates any missing clips, commits them to `audio/`, and deploys.
   After that, only new sentences get generated.

Or locally: `AZURE_SPEECH_KEY=… AZURE_SPEECH_REGION=eastus node tools/generate-audio.mjs`.

Until clips exist, listening exercises are hidden automatically (unless the device has its own Sinhala voice, e.g. some Android phones).
You can swap any clip for a native speaker's recording by replacing the matching `audio/<id>.mp3`.

## 4. Install on your phone

- **iPhone**: open the URL in Safari → Share → **Add to Home Screen**.
- **Android**: open in Chrome → menu → **Install app**.

## Adding lessons

All content lives in `data/course.js`:

- `LEX` — words/phrases: `{ si, en, alt?, emoji?, note?, roAlt? }` (`roAlt` = other romanized spellings to accept when typing).
- `SENT` — sentences: `{ si, g: [one gloss per Sinhala word], en, alt?, speaker? }`.
- `STORIES` — dialogue lines `{ sp, si, g, en }` and questions `{ q, options, answer }`.
- `UNITS[].path` — `lesson` (with `items` and `sentences`), `chest`, `story`, `review` nodes in order.

Run `node tools/check-content.mjs` — it catches missing references and gloss/word-count mismatches. Romanization is generated automatically from the script.

**Please have a native speaker review the Sinhala.** It aims to be natural colloquial Sinhala, but it was drafted with AI help.
