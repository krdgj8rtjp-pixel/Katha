# Katha (කතා) — learn spoken Sinhala, Spanish and Uzbek

A Duolingo-style app for **everyday spoken Sinhala**, **Latin American Spanish** and **Uzbek** (in Cyrillic), aiming at CEFR **A1**.
It's an installable web app (PWA) that runs offline, is hosted free on GitHub Pages,
and can sync your progress across devices through a free Supabase project.

## What's in it

- **Three courses**: Sinhala, Spanish and Uzbek. Tap the course badge (top left) to switch. Streak, XP, gems, quests and friends
  are shared; each course keeps its own path, words and practice.
  - Spanish and Uzbek each cover the whole of A1 in 10 units: Greetings, About me, Food, Numbers & money, Family,
    Getting around, Daily life, Time & weather, Faith (church, the Bible, prayer and talking about what you believe),
    and Health & plans (with simple past and future). About 200 words and phrases, 160+ sentences and 10 stories each.
  - Spanish uses Mexican and US Spanish neural voices.
  - Uzbek is written in Cyrillic, with a 35-letter Cyrillic trainer and the official Latin spelling shown under the
    Cyrillic (toggle in settings). Typed answers are accepted in either alphabet.
  - Pictures are drawn once by meaning and re-cast per course: Sofía, Mateo and a Latin American family for Spanish;
    Dilnoza, Aziz and an Uzbek family for Uzbek.
- **Course path**: units of lessons, treasure chests, a story and a unit review per unit, plus a guidebook (tips + key phrases) for each unit.
  Units 1–8 are written (Greetings, About me, Food & drink, Numbers & money, Family, Getting around, Everyday verbs,
  Faith & church: 157 words and phrases, 122 sentences, 8 stories). Units 9–12 of the A1 map are shown as "coming soon".
  Every word has a hand-drawn picture (`js/pics.js`); every story opens with an animated scene (`js/art.js`).
- **Exercises**: new-word cards, picture choice, meaning choice, match pairs, translate with word tiles (or type),
  build Sinhala sentences from tiles, listen-and-tap, fill in the blank, write it (romanized typing is fine), and speak (record and compare).
  Tap any Sinhala word for its meaning.
- **Letters**: a script trainer covering vowels, consonants and vowel signs, with strength bars per letter.
- **Practice**: spaced-repetition review of your weakest words, a mistakes review, listening practice, and a word list with strength meters.
- **Motivation**: XP, daily goal, streaks (with streak freezes and milestone gifts), hearts, gems, daily quests and a daily chest,
  achievements, a shop. Bonuses: +XP for a flawless lesson and for answers in a row, a 15-minute 2× XP boost (daily chest or shop),
  early-bird and night-owl gems.
- **Friends**: a friend code and invite link per account, follow/unfollow, and a weekly XP leaderboard (Monday–Sunday).
- **Sync**: email + password accounts. Progress merges safely between devices (each device's counters are kept separately, so nothing double-counts).
- **Offline**: a service worker caches the app and audio once you've opened it.

## 1. Put it on GitHub Pages

1. Create a **public** repository (GitHub Pages on a free account needs public), e.g. `katha`, and push this folder to `main`.
2. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. The *Build and deploy* workflow runs on every push. Your app will be at `https://<your-username>.github.io/katha/`.

## 2. Accounts & sync (Supabase) — already set up

The Supabase project **katha** (`tfnvhmuqqhukqgvylwti`, region us-west-1) is created, the `progress` table from
`supabase/schema.sql` is in place with row-level security (tested: each user sees and writes only their own row),
and `js/config.js` already holds the project URL and publishable key.

In the app: **Profile → Account & sync → Create account**. On your other devices, choose *I already have an account* (or sign in from Profile).

Two optional settings in the Supabase dashboard (**Authentication**):
- **URL Configuration → Site URL**: set it to your GitHub Pages URL so the confirmation email links back to the app.
- **Sign In / Providers → Email → Confirm email**: turn it off if you'd rather skip the confirmation email entirely.

Friends use two more tables, also in `supabase/schema.sql`: `profiles` (name, avatar, weekly XP and streak; you can only
read your own row and rows of people you follow or who follow you) and `follows`. The `find_friend(code)` function looks
someone up by exact friend code without exposing anyone else.

To recreate this in a fresh project: run `supabase/schema.sql` in the SQL editor and put the new URL and publishable key in `js/config.js`.
Never put the secret / `service_role` key in the app.

## 3. Voices (Azure) — already set up

Phones rarely ship a Sinhala voice, so the app plays pre-generated clips made with Azure's two Sinhala neural
voices (Thilini, female; Sameera, male). The whole course is ~400 short clips — a few thousand characters,
well inside the free tier. Spanish uses `es-MX-DaliaNeural` (narrator, Sofía), `es-MX-JorgeNeural` (Mateo)
and `es-US-AlonsoNeural` (John). Uzbek uses `uz-UZ-MadinaNeural` (narrator, Dilnoza) and `uz-UZ-SardorNeural`
(Aziz and John; Azure has only these two). Azure's Uzbek voices and speech recognition work in the Latin alphabet,
so the app converts Cyrillic to official Latin spelling (`uzLatin` in `js/translit.js`) before generating audio,
and compares what you said in Latin too. Clips are still named by the Cyrillic text.

What exists in Azure (subscription *Azure subscription 1*, resource group `katha-rg`, West US 2):
- `katha-speech` — a Speech resource on the free **F0** tier.
- `katha-github` — a managed identity whose federated credentials trust only this repo's `main` branch
  (GitHub sends the subject as `repo:krdgj8rtjp-pixel@357149014/Katha@1466179636:ref:refs/heads/main`;
  the plain-name form is registered too), with the *Cognitive Services User* role on `katha-speech` only.

On every push, the workflow signs in to Azure as that identity (no stored password or key), reads the speech key,
generates any clips that are missing, commits them to `audio/`, and deploys. Re-running is cheap: existing clips are skipped.

Locally: `AZURE_SPEECH_KEY=… AZURE_SPEECH_REGION=westus2 node tools/generate-audio.mjs`.
You can swap any clip for a native speaker's recording by replacing the matching `audio/<id>.mp3`.

## Speaking checks (Azure speech-to-text via Supabase)

Speaking exercises record you, convert the recording to 16 kHz WAV in the browser, and send it to the
Supabase Edge Function `transcribe` (`supabase/functions/transcribe`). The function:
- only answers signed-in users,
- reserves the seconds against caps in `public.speech_usage` (15 min/day, ~4.2 h/month — Azure's free tier is 5 h/month),
- calls Azure speech-to-text for `si-LK` with the key stored as the function secret `AZURE_SPEECH_KEY`,
- returns what it heard. The app grades it leniently (word matches, spelling variants, digits) and highlights missed words.

Turn it off under Profile → Settings → *Check my speaking*. Without sign-in, speaking falls back to record-and-compare.

## Adding lessons

Each course's content lives in its own file (`data/si.js`, `data/es.js`). The field is called `si` in both — it simply
means "the target-language text". Spanish ids start with `es` so they never clash with Sinhala ones in saved progress.

- `LEX` — words/phrases: `{ si, en, alt?, pic?, note?, roAlt? }` (`roAlt` = other romanized spellings to accept when typing;
  `pic` = reuse another word's picture, e.g. Spanish `es_agua` uses the Sinhala `vathura` picture).
- `SENT` — sentences: `{ si, g: [one gloss per Sinhala word], en, alt?, speaker? }`.
- `STORIES` — dialogue lines `{ sp, si, g, en }` and questions `{ q, options, answer }`.
- `UNITS[].path` — `lesson` (with `items` and `sentences`), `chest`, `story`, `review` nodes in order.

Run `node tools/check-content.mjs` — it catches missing references and gloss/word-count mismatches. Romanization is generated automatically from the script.

## Adding another language

Copy `data/es.js` (Latin alphabet) or `data/uz.js` (another script) to a new file, translate it, add an entry to
`COURSES` in `data/course.js` (name, language code, speech-recognition locale, script, badge letter, voices, and a
letters trainer if it has its own script), and run the checker. Pictures are shared by meaning, and the
audio generator picks the new voices up automatically.

**Please have native speakers review the Sinhala and the Uzbek.** It aims to be natural colloquial Sinhala, but it was drafted with AI help.
